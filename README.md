# Ayame PaperDoll (DS Compat)

[![License: LGPL-3.0-or-later](https://img.shields.io/badge/License-LGPL--3.0--or--later-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0)

A fork of [Ayame PaperDoll](https://github.com/AyameMC/Ayame-PaperDoll) with full [DragonSurvival](https://github.com/DragonSurvivalTeam/DragonSurvival) compatibility.

## About

This is a modified build of Ayame PaperDoll (originally by **LucunJi** / **HappyRespawnanchor**) that adds a compatibility layer so the paper doll renders correctly while playing as a DragonSurvival dragon.

### DragonSurvival fixes included

- Dragon body no longer disappears during glide
- Mirror mode renders the dragon's front face correctly (no inside-out rendering)
- Wing z-fighting / flickering eliminated
- Head, neck, and tail pitch follow the paper doll's pose without twitching
- No right-bias during glide; tail no longer flips at the "dividing line"
